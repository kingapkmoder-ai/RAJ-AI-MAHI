# Mahi AI

React + TypeScript + Vite voice-to-voice Gemini Live starter.

## Run
1. `npm install`
2. Copy `.env.example` to `.env` and put your Gemini API key in `VITE_GEMINI_API_KEY`.
3. `npm run dev`

For production, do not expose a long-lived Gemini API key in a public frontend. Use a backend/token broker for a real deployment.
